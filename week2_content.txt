Week Overview 
Week 2 builds on the foundations of Week 1 by introducing advanced prompt 
engineering patterns and structured tool calling , the two pillars that allow an LLM to 
move from passive conversation to reliable, controllable action. 
  
Detail 
Information 
Week Dates 
Monday 29 June ΓÇô Friday 3 July 2026 
Theme 
Prompt Engineering & Tool Calling 
Primary Stack 
Python ┬╖ LangChain ┬╖ Groq API ┬╖ Pydantic v2 ┬╖ httpx 
Total Commitment 
20 hours (4 hours/day ┬╖ 5 days) 
Deliverable Due Friday 
1 Intermediate Project + 1 Production Project (choose one 
of each) 
  
Learning Objectives 
Master advanced prompt engineering patterns (CoT, ToT, few-shot, meta-prompting) 
Implement function/tool calling with structured outputs using Pydantic 
Build agents that call external APIs, databases, and code execution engines 
Handle tool call errors, retries, and fallbacks gracefully 
Design tool schemas following OpenAI/Anthropic best practices 
Build a multi-tool agent pipeline end-to-end

Hands-on Labs 
Complete all three labs over the course of the week. Each lab builds toward the skills 
required for your Friday project submission. 
  
Lab 2.1: Structured Output Extractor 
Build a tool that takes unstructured job postings and extracts: title, company, salary 
range, required skills, location, and remote status , all as a validated Pydantic model. 
  
Lab 2.2: Multi-Tool Research Agent 
Build an agent with 5+ tools: web_search_mock, calculate, get_current_date, 
summarize, classify_sentiment. The agent must correctly route queries to the right 
tool. 
  
Lab 2.3: Error Recovery Agent 
Build an agent that handles tool failures: if a tool fails, it tries an alternative. Log all 
attempts and outcomes. Implement exponential backoff for rate limit errors.
